# Cagan IP TV v0.5

## v0.5 changes

- Channel category selection is preserved while opening/closing the player.
- Returning from a Sports/News/etc. channel returns to the same category instead of `Tüm Kanallar`.
- New Cagan IP TV visual identity added.
- Android phone launcher icon and round icon added.
- Android 8+ adaptive launcher icon added.
- Android TV / TV Box 320x180 banner added.
- In-app Cagan IP TV logo added to playlist and channel screens.
- v0.4 TV focus UI and remote playlist behavior preserved.
- Existing working GitHub Actions workflow remains the baseline.

## Remote config

`CAGAN_CONFIG_URL` must be defined as a GitHub Actions repository secret and point to the raw JSON config URL.
